# Ocean Controls application

Jillur Rahman.

Run npm ci, npm run dev, npm test and npm run build from this directory. The generated dist folder is the static GitHub Pages publication. Source products and documents live in src/data, shared logic in src/domain and individual pages in src/pages. Supplied assets and accepted illustrative editorial images are in public/assets.

Catalogue counters distinguish full-source totals from browsable preview records. Commerce and forms remain explicit demonstration flows; live integrations require separate production implementation.
